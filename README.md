# Reconocimiento facial mediante redes neuronales siamesas

## Descripción

Este proyecto corresponde a una práctica académica de reconocimiento facial mediante técnicas de Deep Learning, utilizando redes neuronales siamesas (Siamese Neural Networks), TensorFlow y Keras.

El objetivo es comprender cómo se representan las imágenes faciales mediante embeddings y cómo se comparan para verificar si dos imágenes corresponden a una misma identidad.

## Tecnologías utilizadas

- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

## Conceptos desarrollados

- Preprocesamiento de imágenes faciales.
- Redes neuronales siamesas.
- Generación y comparación de embeddings.
- Triplet Loss.
- One-shot Learning.
- Few-shot Learning.
- Evaluación de similitud entre identidades.
- Limitaciones del reconocimiento facial con datos sintéticos y reales.
